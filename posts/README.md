# how to post

Each post is a page at hashawn.com/blog/<slug>/

1. copy `_template.md` to `<slug>.md` in this folder (lowercase, dashes, no spaces)
2. fill in `title`, `date`, and optionally `say` (one line he babbles when the post opens)
3. add `"<slug>"` to `/posts.json`, newest first
4. commit and push

Images go in `/assets/` and are referenced as `/assets/name.jpg`. No build step.
