what is this

A context-mixing compressor, the family that wins the benchmarks and that nobody ships because it's slow. It predicts every bit from what came before, with a tiny neural net that learns as it goes, and a range coder turns the predictions into bytes. The decoder runs the exact same net, so the output is bit-exact. It beats gzip, bzip2 and xz on text and code. It won't beat anything on photos, video or zips, those are already squeezed.

The code runs as WebAssembly inside this page, around 2MB a second. A big file takes a while and the bar is honest.
