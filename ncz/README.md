# ncz (Rust port) — the engine behind hashawn.com/tools/compress

Byte-for-byte port of the Python reference in `~/ncz/ncz.py` (context mixing, PAQ/lpaq
lineage, `NCZ2` streams). Either side decodes the other; verified on text, code and random data.

Build the web module and copy it into the tool:

```bash
cd ncz
cargo build --release --lib --target wasm32-unknown-unknown
cp target/wasm32-unknown-unknown/release/ncz.wasm ../tools/compress/ncz.wasm
```

Native CLI for cross-checks (`cargo build --release --bin nczcli`):

```bash
./target/release/nczcli compress   in  out.ncz
./target/release/nczcli decompress out.ncz back
```

`src/tables.rs` is generated by Python (round-half-even) so the logit tables match exactly.
Changing the model changes the stream format: bump the magic if you do.
